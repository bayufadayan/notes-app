 Cara install:

 1. Clone repository
 2. Buka terminal
 3. Install dependensi dengan perintah `npm install`
 4. Buat file `.env` dan isi dengan `BASE_URL=https://notes-api.dicoding.dev/v2`
 5. Jalankan perintah `npm run start-dev`
 6. Buka browser dan buka `http://localhost:8080`
